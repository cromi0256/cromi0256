# 🖐️Introduction

### 운영과 설명에 중심을 둔 ML/AI 엔지니어

데이터 분석부터 모델 구현까지 과정, 검증, 결과, 인사이트를 제공합니다.

또한, 모델을 프로덕션 환경에 배포하여 모니터링 및 유지보수 합니다.

신뢰할 수 있는 모델 설계로 지속 가능한 서비스를 운영합니다.

매주 [실전 가이드](https://github.com/cromi0256/core/tree/main/Guides)를 작성하여 독점적인 영감을 줍니다.

## 📄주요 프로젝트

### [Project01](https://portfolio2026-topaz-three.vercel.app/) : 데이콘 서울시립대 경진대회 우승자의 머신러닝 전략
- Problem: 축구 경기 데이터에서 마지막 패스 후 공의 좌표 예측
- Approach: Permutation Importance를 바탕으로 여러 특성을 실험하며, 오차 분석을 통해 특정 패턴을 포착
- Contribution: 데이터 분석, 데이터 전처리, 특성 공학, 모델 훈련, 모델 검증, 모델 배포
- Result: 유클라디안 거리 오차 12.83347; 참가팀 937팀 중 11위
- Tech Stack: `Python` `Pandas` `AutoML` `Matplotlib`
- [레포지트리](https://github.com/cromi0256/core/tree/main/Projects/[Project01]/[Project01]DaconCompetitionTop11)

### [Project03v2](isops.onrender.com) : 해석 중심 ML 모델 원격 배포
- Problem: iris 데이터셋을 활용하여 붓꽃의 품종을 예측
- Approach: 단순 예측이 아닌 결과 해석, 이상치 여부 확인, SHAP 해석을 추가하여 투명한 설명
- Contribution: 모델 설계, 모델 패키징, 컨테이너화, 원격배포
- Result: 원격 웹 서비스를 구축; EBM 분류기 결과 설명, 이상치 탐지, SHAP값 이미지 출력
- Tech Stack: `Python` `interpretml` `scikit-learn` `SHAP` `FastAPI` `streamlit` `Docker`
- [레포지트리](https://github.com/cromi0256/IrisOps)
